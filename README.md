# TaskFlow API

A multi-user task management API built with FastAPI and PostgreSQL.

## Tech stack
FastAPI · PostgreSQL · SQLAlchemy · Alembic · Pytest · uv · Docker

## Getting started
```bash
uv sync
cp .env.example .env
```
